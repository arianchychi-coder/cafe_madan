# کافه معدن | اصلاح محدود فیلد حوزه فعالیت

این فایل ادامه مستقیم نسخهٔ `CafeMadan_Vercel_LogoLines_GuestPhotos_Final.zip` است.

تنها تغییر عملکردی در سایت: فیلد «حوزه فعالیت» در فرم پیش‌ثبت‌نام از منوی سفارشی به عنصر استاندارد و واکنش‌گرای `<select>` تبدیل شده است. شش گزینه و نام فیلد (`role`) بدون تغییر مانده‌اند. ظاهر کادر در حالت بسته (ارتفاع، رنگ، حاشیه، فونت و فلش طلایی)، اعتبارسنجی، پیام خطا و ارسال فرم با API قبلی سازگار است.

در پروژه فقط سه فایل `index.html`، `css/custom.css` و `js/main.js` برای همین فیلد اصلاح شده‌اند؛ تصاویر، لوگو، انیمیشن، محتوای سایر بخش‌ها، سرور ثبت نام و تنظیمات Vercel تغییر نکرده‌اند.

## استقرار روی Vercel

محتویات فایل ZIP را در ریشه پروژه قرار دهید. Framework Preset را روی Other قرار دهید و Build Command را خالی بگذارید. برای ارسال واقعی فرم، متغیرهای `RESEND_API_KEY`، `REGISTRATION_TO_EMAIL` و `REGISTRATION_FROM_EMAIL` باید مطابق نسخه قبلی تنظیم شوند.

## تست

در Chromium نمایش فرم با نسخه قبلی در عرض‌های ۲۸۰، ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل مقایسه شد. اندازه، رنگ زمینه، رنگ حاشیه، فونت و گردی کادر حفظ شده‌اند. انتخاب از `<select>`، ثبت گزینه، نمایش خطای انتخاب‌نکردن و ارسال شبیه‌سازی‌شده فرم با موفقیت تست شدند. منوی بازشده از رابط استاندارد مرورگر/سیستم‌عامل استفاده می‌کند و ظاهر داخلی آن ممکن است بین اندروید و iOS متفاوت باشد.
